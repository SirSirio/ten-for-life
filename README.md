# Ten for Life

A 5/10/15-minute morning routine (mobility, breath, qigong) plus a separate 5/10-minute posture programme.
It rotates exercises, introduces new ones gradually, adapts to your equipment and logs every session.
It runs as an installable web app: works offline, and syncs between devices, end-to-end encrypted.

**The idea:** the app's code is public and generic. Everything about you (your exercise texts, notes,
posture baseline, log) lives only on your devices, and travels between them encrypted with your passphrase.

## Folder layout

| Folder | What it is | On GitHub? |
|---|---|---|
| `app/` | The app's source code and the build script. Generic, nothing personal. | yes |
| `app/build/` | Generated by `python app/build.py`. Never edit by hand. | no |
| `.github/workflows/` | Rebuilds and publishes the site on every push. | yes |
| `private/profile.json` | **Your personal profile**: your own exercise texts, notes, posture baseline. | **no** |
| `research/` | The research reports and notes the routine is based on. | **no** |
| `archive/` | The original export zip from claude.ai. | no |

## 1. Put the app online (one time, ~10 minutes)

1. **Create an empty repo** on github.com named `ten-for-life`, **public** (free GitHub Pages requires it;
   the code is generic, `private/` and `research/` never leave this computer). Don't add a README.
2. **Push this folder** (it is already a git repo with a first commit):
   ```
   git remote add origin https://github.com/<your-username>/ten-for-life.git
   git push -u origin main
   ```
3. On GitHub, in the repo: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
   Then **Actions → Deploy to GitHub Pages → Run workflow**. After a minute the app is at
   `https://<your-username>.github.io/ten-for-life/`.

## 2. Install it on your phone

Open that link in **Chrome** on Android → ⋮ menu → **Install app** (or "Add to Home screen").
iPhone: Safari → Share → **Add to Home Screen**. It opens full screen like a normal app and works offline.

## 3. Load your profile

Copy `private/profile.json` to the phone (USB, Google Drive, or email it to yourself and download it),
then in the app: **Settings → Personal profile → Load file**. 21 exercises switch to your own text and your
posture baseline appears in Library. Do the same on the computer if you also use the app there, or just
connect sync (next step) and the profile arrives by itself.

## 4. Turn on sync (optional, recommended)

1. In the app: **Settings → Sync between devices → Make a token**. GitHub opens with only **gist**
   ticked. Set an expiration you like, **Generate token**, copy it.
2. Paste the token, choose a **passphrase** (a sentence you will remember, 8+ characters), **Connect**.
3. On the other device: same token, same passphrase.

- Everything (log, settings, profile) is **encrypted on the device** before upload. GitHub stores one
  private gist containing scrambled text; without your passphrase it cannot be read, by anyone.
- If you forget the passphrase, the synced copy is lost, but each device keeps its own data. Disconnect
  and connect again with a new passphrase on a fresh gist (delete the old one at gist.github.com).
- Changes upload a second or two after you make them; the app pulls the latest when it opens or comes
  back to the front. Offline, it saves on the device and catches up next time.

## Changing your personal content (fast)

- **On the phone:** Library → open an exercise → **My note** → Save. Posture baseline: Settings → Posture.
- **A lot at once:** edit `private/profile.json` on the computer (or ask Claude to), then
  Settings → Personal profile → Load file. With sync on, every device gets it within seconds.
- **The other way round:** Settings → Personal profile → Download saves the current profile, including
  notes written on the phone. Keep `private/profile.json` updated with it as your backup.
- **Quick edits in the app:** Settings → Personal profile → Edit as text.

Profile format: `exercises.<id>` replaces any of `why`, `protects`, `steps`, `pitfalls`, `evidence` for that
exercise (leave a field out to keep the general text); `notes.<id>` is a short personal note shown at the
top of the exercise; `anchors.<id>` replaces a weekly goal's explanation; `postureNote` is the baseline.
Exercise ids are in `app/src/exercises.js`.

**Bringing your log from the claude.ai version:** there, Settings → Copy export; in the new app,
Settings → Your data → Import… → paste → Replace.

## Changing the app itself

Edit the files in `app/src/` (or `app/data/` for videos), then:

```
python app/build.py                                       # builds app/build/site/
python -m http.server 8080 --directory app/build/site     # open http://localhost:8080
```

Commit and push; the site updates itself within a minute or two, and installed copies pick up the new
version the next time they open online. Keep anything personal out of `app/`: it belongs in the profile.

Not medical advice. See `research/README.md` for where the routine comes from.
